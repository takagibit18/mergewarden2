# ADR-0002 · 真实语法分析与可核验代码关系

状态：已确定（路线）；细节待实现

日期：2026-09-20

## 背景
用户要求 AST + Tree-sitter；骨架提供真正解析起点，不伪装完整图服务。

## 决策 / 当前建议
使用 Tree-sitter CST -> 统一 AST/语法事实 -> 作用域/导入解析 -> 可查询图。禁止正则替代、执行 import 或仅靠同名连边。

## 约束与代价
Python 首先支持是骨架建议。SQLite 是存储草案。调用边的 candidate/unresolved 状态必须保留。

## 验收
以 docs/ROADMAP.md 和 docs/VALIDATION.md 为准；状态更新必须保留历史原因。

## M0 联调记录

web-tree-sitter 0.27.0 与官方 Python grammar 0.25.0 已安装实测；grammar commit、ABI 15 和 SHA-256 固定于 integrations/tree-sitter/grammars/python.lock.json。作用域/导入 resolver 和图存储仍未实现。
